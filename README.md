# Bangladesh Bus Simulator
A browser-playable 3D driving prototype designed for Android browsers.

## Run
1. Extract the ZIP.
2. Open `index.html` in Chrome/Firefox while online. The Three.js engine loads from jsDelivr CDN.
3. Choose a route and mode, then tap Start Engine.
4. Landscape orientation is recommended.

## Controls
- Left / Right: steer
- ACCEL: accelerate
- BRAKE: slow down
- CAMERA: switch chase/cockpit-style follow camera
- HORN / LIGHTS: dashboard actions

## Included
- Procedural 3D bus, road, roadside trees/buildings, traffic and bridge scenery
- Dhaka, Padma, Jamuna and coastal route selections
- Career reward loop, free-drive mode, speed/fuel/money HUD and minimap
- Mobile touch controls

## Notes
This is a playable first build. It uses procedural placeholder scenery rather than licensed photogrammetry or official bus assets. A true 1:1 geographic map, detailed branded bus models, passenger boarding, sound assets and persistent career saves are planned for later versions. Internet access is required for the Three.js CDN.
